### Judging Criteria

* **Technological Implementation**: How thoroughly and skillfully does the project use AI in an optimized way? Does the code reflect genuine effort and a working, non-trivial implementation?
* **Design**: Does the project deliver a working or runnable project that has a complete, coherent product experience — not just a technical proof of concept?
* **Potential Impact**: Does the project make a credible, specific case for solving a real problem for a real audience — and does the solution actually address that problem based on what's demonstrated?
* **Quality of the Idea**: How creative and novel is the concept and does the project differ from existing concepts?
