    Dynamic Page Templates & Admin Integration

    A comprehensive manual on creating, editing, deleting dynamic product category pages and linking them to the recursive site megamenu.

    Overview & Architecture

    The Geosynthetics Africa platform employs a highly flexible, data-driven approach to product page creation. Rather than hardcoding structural pages, administrators can visually build and update product categories directly from the admin panel.

    The connection is fully unified: when an admin modifies values in the 12-tab Page Templates visual builder, changes are saved to Supabase and immediately pushed to the public website, rendering custom titles, specifications tables, FAQs, highlight badges, and installation warnings in real-time.

    Supabase Config Backing

    All template configurations live in the site_config table under the key template_product_categories as a single JSON object. This eliminates complex schema migrations while keeping data atomic and highly cached.

    Zero-Downtime Seeding

    If the database is clean, visiting the admin template page prompts the user to "Seed Defaults" which populates all 8 canonical geomembrane types (HDPE, LLDPE, PVC, EPDM, PP, Textured, Speciality, and Floating Covers).

    Category Alignment

    Protects parent categories (e.g. Geomembranes) by blocking them in Page Templates. Instead, editing their layout content is done directly in the Site Builder, where custom inputs dynamically merge onto premium fallback layouts.

    Administrator Notice
    Access to both Page Templates and Site Builder is restricted to verified administrators and staff. Attempting to access these pages without appropriate session roles will redirect to the secure login gateway.

    Creating a Page Template

    Adding a brand-new dynamic sub-category is fully streamlined. Follow this step-by-step procedure to add a page correctly:

    1

    Access Page Templates

    Log into the admin portal using your credential console. Once inside, locate and click the Product Page Templates item from the administration navigation menu or visit /admin/page-templates.

    2

    Initialize a New Slug

    In the left sidebar of the templates builder, click the + New Template button. A small text input will appear inside the sidebar area.

    3

    Enter Slug Name

    Type in the exact lowercase URL-safe slug for your product sub-page (e.g. custom-clay-liners). Ensure you use only alphanumeric characters and hyphens. Click Create to initialize local defaults.

    4

    Build Out Content & Save

    The template is added instantly. Now, go tab by tab (Hero, Description, FAQs, Table) and fill in your values. Once finished, click the glowing Save All button in the top right header to commit it to Supabase.

    Editing Page Contents

    Editing page contents is fully structured into 12 visual tabs. Select your target category from the sidebar and use the designated sub-panels:

    Properties & Specs Table

    Located in the Properties Table tab. Build a robust grid of physical specs. You can dynamically click + Column to add new test vectors (e.g. "Metric Value", "Imperial Value") or + Row to add custom polymer test properties (e.g. "Puncture Resistance").

    Badge Callouts

    Managed in the Highlights tab. Configure a set of micro key-value pairs (e.g., "Standard Roll: 7.0m", "Warranty: 20 years"). These are automatically compiled into visual pill badges that render prominently under the H1 page header.

    FAQs Accordion

    Located in the FAQs tab. Add recursive question and answer sections. Administrators can easily update pricing guidance, welding tolerances, or storage procedures which customers can slide open instantly.

    Cross-Linking Products

    Located in the Products tab. Link actual items from the primary catalog by entering their exact product names, short descriptions, and technical links. These render as product recommendations at the bottom of the page.

    Pro Tip: Real-time Live Preview
    Unsaved changes are clearly marked with an amber ● Unsaved indicator. You can preview your work at any time by clicking the Preview button in the active category header bar. This launches the exact draft in a separate browser tab before committing the save.

    Deleting a Template Page

    If a product line is discontinued or consolidated, you can easily purge its dynamic template configuration from the platform:

    1

    Hover Target Template

    Locate the template you wish to delete in the left sidebar of the templates builder interface.

    2

    Trigger purges

    Click the red Trash Icon that dynamically fades in next to the template label on hover. This triggers an Alert Dialog window.

    3

    Confirm and Commit

    Confirm the action inside the alert box. Lastly, click the global Save All button in the top right corner. The database record is immediately purged, and the public route will safely output a clean 404 response.

    Linking to Mega Menu

    Creating a new template page doesn't automatically publish it in the navigation headers. To make your new page accessible to public users, you must register it in the megamenu hierarchy. Thanks to our unified system, this is now a simple **1-click automatic action**:

    1

    Check Menu Status Pill

    Look at the active template header bar inside the Page Templates page. If the template is not in the menu, you will see a warning pill: ✕ Unlinked (Hidden from Nav Menu).

    2

    Link Instantly

    Click the glowing ⚡ Link to Menu action button right next to the status pill. A dialog box will appear asking you to choose the parent menu category.

    3

    Select Parent & Confirm

    Select the desired parent group (e.g. Geomembranes or Geotextiles) from the dropdown list and click Confirm Link. The system will automatically build the required JSON structures, resolve parameters, purge old duplicate paths, register the link in Supabase, and update the status pill to green instantly!

    Alternative: Site Builder Autocomplete
    If you are already inside the Site Builder (/admin/site-builder) configuring links, you don't need to manually type labels or path names. Simply add/select a tree node, locate the ⚡ Auto-fill from Page Template panel under the Identity tab, and pick your template. All parameters will instantly auto-populate without any risk of spelling errors or 404s!

You can configure up to 3 custom call-to-action buttons with individual labels and target paths (e.g. /contacts).

    3. Application Systems

    Manage the grid of 6 primary application systems (e.g., MINING SYSTEMS, WATER CONTAINMENT). Administrators can edit section titles, add/remove cards, upload rich background images, and customize the click-through URLs. Cards are fully collapsible inside the visual editor to simplify organization.

    4. Global Partners Carousel

    Customize the best-in-class materials brand section. Add or remove partner logos (e.g., Solmax) and brand names to present active industrial alliances, which render in a sleek, infinite auto-scrolling ticker strip on the public landing page.

    5. Services Grid & Quality Box

    Govern the middle section of the homepage. The Left Grid lets you edit 6 services cards (icon, title, and mini-description). The Right Box lets you manage the high-visibility dark QA/QC assurance panel, including editable checkmarks (e.g., Weld Integrity Testing) and background illustrations.

    6. Stats & Presence Map

    Edit counter metrics (e.g. "20+ Years Experience", "1000+ Projects") and specify pan-African branches. Adding a branch location name (e.g., Ghana) and type (e.g., HQ) automatically triggers an animated pulsing map coordinate pin over the custom vector outline map of Africa!

    7. Project Case Studies

    Manage the case studies showcase cards by adding cover photos, categories (e.g., TSF LINING SYSTEM), location flags, system details, and titles. You can also customize the adjacent high-impact "Explore Our Catalogue" search teaser box and button.

    8. BOQ Callout Banner

    Optimize the red primary call-to-action bar above the website footer. Customise the bold headline ("SUBMIT YOUR BOQ."), descriptive paragraph, and two distinct primary action buttons to maximize business conversions and quote requests.

    Managing Application Categories & Sub-pages

    The Geosynthetics Africa navigation systems are built dynamically. Both application categories (e.g. Containment & Lining) and their corresponding nested sub-pages (e.g. Mining TSF Lining) can be customized, reordered, added, or deleted directly in the Admin Control Panel.

    The administration of applications is divided into two primary workspaces: structural hierarchy editing in the Site Builder (/admin/site-builder), and content detailing in the Page Templates editor (/admin/page-templates). All configurations are synced atomically to the Supabase site_config database table under the keys hierarchy_applications and template_applications.

    1. Navigation Tree & Hierarchy Management

    To modify the categories listed in the header's Applications mega menu dropdown, navigate to the Site Builder (/admin/site-builder) and select the Applications tab:

    1

    Reorder Items (Drag & Drop)

    Hover over any item in the category tree. Click and hold the vertical drag handle (⋮⋮) next to the item, then drag it up or down to reorder the items or move sub-pages under a different parent category.

    2

    Add a Top-Level Category

    Enter the label of the new category inside the input box at the bottom of the tree sidebar (e.g., Waterproofing) and click the + button. The system will automatically generate a corresponding URL slug.

    3

    Add a Child Sub-page

    Hover over any parent category in the tree and click the small blue + icon that appears on the right edge. Type the name of the new sub-page and press Enter to instantly create the sub-item.

    4

    Delete an Item

    Hover over the category or sub-page you wish to delete and click the red Trash icon. Confirm the action in the alert box. Note that deleting a sub-page here will remove it from navigation, but you must click Save to commit it.

    5

    Save to Database

    Any structural alterations are flagged as unsaved. Click the Save Applications button in the top-right header to commit all structural changes to Supabase.

    2. Editing Category Page Content & Layout Templates

    To update the copy, images, and search engine metadata of category landing pages, navigate to Page Templates (/admin/page-templates) and choose the Application Templates sub-tab:

    Hero Section Tab

    Configure the top banner of the application landing page. Edit the main Page Title (H1), upload a custom background photo using the image picker, and enter a detailed subtitle description.

    Sub-systems Content Tab

    Manage the sub-systems list. Each item is rendered as a stylized card on the category landing page. Administrators can add, remove, and reorder these items dynamically using the String List editor.

    SEO Meta Tab

    Update metadata to optimize organic Google rankings. Write a custom Meta Title, a meta description explaining the system value, and comma-separated meta keywords (e.g. tailings storage, pond liners).

    Static vs Custom Slugs
    Protected static categories built into the main menu structure (e.g., mining-systems, water-containment) cannot be deleted. However, administrators can create new custom categories or templates dynamically. Deleting custom categories will prompt a confirmation dialog to prevent accidental data loss.

    Tracking & Cookie Flow

    The Geosynthetics Africa platform implements a modern, highly secure, and fully compliant privacy consent structure. Designed to respect international data privacy regulations (such as GDPR, CCPA, and South Africa's POPIA), third-party tracking scripts are loaded dynamically and strictly in accordance with each visitor's selected preferences.

    1. Admin Integration Portal

    Administrators can connect third-party analytics suites without modifying any code. Navigate to the dedicated Tracking & Cookies control panel (/admin/tracking) under Pages SEO.

    Google Analytics 4 (GA4)

    Input your GA4 Measurement ID (formatted as G-XXXXXXXXXX) found in your Google Analytics Admin console under Data Streams > Web Stream Details. GA4 tracks user engagement, pageviews, events, and funnel conversions.

    Google Tag Manager (GTM)

    Input your GTM Container ID (formatted as GTM-XXXXXXX) visible at the top of your Tag Manager workspace dashboard. GTM acts as a unified container to deploy advertising pixels, heatmaps, and custom marketing scripts.

    Database Architecture
    Credentials saved in the tracking control panel are committed to the site_config database table under the row key tracking_config. This data is structured as a simple JSON object: { googleAnalyticsId: string, googleTagManagerId: string }, allowing direct queries and fast caching.

    2. Granular Cookie Consent Banner

    When a new visitor arrives, a custom glassmorphic CookieConsent notice slides up from the page bottom after a 1000ms delay. The banner presents three options:

    1

    Necessary Cookies (Always Active)

    Required for basic platform operations, user sessions, routing, authentication security, and recording user settings. These cannot be disabled.

    2

    Analytical Trackers

    Controls the dynamic loading of Google Analytics and Google Tag Manager to audit traffic patterns and measure site performance metrics anonymously.

    3

    Marketing Pixels

    Enables specialized campaign tracing, retargeting tags, and custom conversion events for advertising networks (e.g. LinkedIn, Meta).

    3. Storage & Event Lifecycle Flow

    The cookie lifecycle is designed for seamless transitions, zero-delay initialization, and persistence:

    Preference Storage

    When consent preferences are saved, the state is persisted in localStorage under the key gsa-cookie-preferences as JSON:
    { "necessary": true, "analytics": false, "marketing": false }

    Grace Period Dismissal

    If a visitor clicks the close (✕) button instead of accepting/declining, the banner is dismissed and a timestamp is recorded in gsa-cookie-dismissed-at. The banner is hidden for a 3-hour grace period before prompting again.

    Backward Compatibility

    To maintain continuity for legacy visitors, any existing binary cookie consent saved as gsa-cookie-consent is auto-detected on load and migrated into the new granular preferences object structure seamlessly.

    Reactive Event Dispatcher

    Every time a visitor modifies cookie settings, the consent panel dispatches a custom window event: window.dispatchEvent(new Event("gsa-cookie-preferences-changed")). This triggers immediate response from loading scripts.

    4. Dynamic Script Injection (TrackingLoader)

    The TrackingLoader is a global, non-rendering React component mounted in the root page layout. It orchestrates script injection under strict conditions: 

    // 1. Listen for consent changes reactively
window.addEventListener("gsa-cookie-preferences-changed", loadPreferences);

// 2. Dynamic Injection checks (GDPR/POPIA compliance)
if (preferences.analytics && config.googleAnalyticsId) {
  // Create and append GA script dynamically inside document.head
  const script = document.createElement("script");
  script.id = "gsa-google-analytics";
  script.src = `https://www.googletagmanager.com/gtag/js?id=${gaId}`;
  document.head.appendChild(script);
}
    Preventing Duplicate Injections
    To prevent performance-degrading duplicate script initializations, all dynamically injected scripts are given unique IDs (e.g. gsa-google-analytics, gsa-google-analytics-init, gsa-google-tagmanager). The loader checks for the existence of these elements before executing any DOM manipulations.

    Media Center Operations

    The Geosynthetics Africa platform features an integrated Media Center inside the admin control panel. This hub acts as the centralized file hosting and asset management engine for the entire website, removing the need for manual FTP client access or direct Git repository commits for simple asset updates.

    Whether you need to upload high-resolution product photography, detailed product brochures, engineering data PDFs, or promotional/instructional videos, the Media Center provides a fast, drag-and-drop workflow that optimizes and hosts your files instantly.

    Supported File Types

    The Media Center accepts a comprehensive range of file extensions including images (.jpg, .png, .webp, .svg), document sheets (.xlsx, .docx), standard pamphlets and brochures (.pdf), and high-definition video files (.mp4, .webm).

    All files are securely uploaded directly to our high-speed, globally distributed Supabase Storage Buckets. This guarantees rapid content delivery network (CDN) responses and zero application server load when clients download huge documents.

    Automatic Image WebP Converter
    When uploading raster images like PNGs or JPEGs, the control panel dynamically compresses and converts them into the modern .webp format to ensure your web pages load lightning-fast for cellular users across Africa, saving up to 80% bandwidth with zero perceptible quality loss.

    Technical & Architecture Reference

    For software engineers and AI coding agents extending this codebase, please adhere to the following architecture rules and structures:

    1. Strict TanStack Router/Page Separation

    In order to allow TanStack Router to properly code-split routes into light chunks and prevent warning console logs during bun dev, never export page JSX components directly from route files. Route files must only configure createFileRoute, while the full JSX live separately in pages. 

    // ❌ AVOID - exporting component from route file breaks code-splitting
export function ProductCategoryPage() { ... }
export const Route = createFileRoute("/products/$category")({ component: ProductCategoryPage });

// ✅ CORRECT - route configuration file only exports Route config
import { ProductCategoryPage } from "@/pages/ProductCategoryPage";
export const Route = createFileRoute("/products/$category/")({
  loader: async ({ params }) => { ... },
  component: ProductCategoryPage
});

    2. Supabase Integration Hooks

    Fetching from Supabase uses cached loaders and helper APIs. The core function is getProductPageContent(slug), located in src/data/product-pages.ts. It fetches custom family templates, but also seamlessly resolves parent categories by querying the visual hierarchy tree (hierarchy_products) and merging site builder customizations onto premium default layouts: 

    export async function getProductPageContent(slug: string): Promise<ProductPageContent | null> {
  // 1. Query custom templates for product family sub-pages
  const { data } = await supabase
    .from("site_config")
    .select("value")
    .eq("key", "template_product_categories")
    .maybeSingle();

  if (data?.value?.[slug]) {
    return data.value[slug] as ProductPageContent;
  }

  // 2. Dynamic fallback logic for the 8 parent product categories
  const parentCategories = ["geomembranes", "geotextiles", "geogrids", "geocells", "gcls", ...];
  if (parentCategories.includes(slug)) {
    const fallback = generateParentCategoryFallback(slug);
    
    // Merge customized elements edited inside the Site Builder tree
    const { data: hierarchyData } = await supabase
      .from("site_config")
      .select("value")
      .eq("key", "hierarchy_products")
      .maybeSingle();
      
    if (hierarchyData?.value?.items) {
      const matched = hierarchyData.value.items.find((i: any) => i.slug === slug);
      if (matched?.pageContent) {
        return { ...fallback, ...matched.pageContent };
      }
    }
    return fallback;
  }
  return null;
}

    3. Unified Parent Categories vs. Sub-Page Templates

    To prevent data duplication and configuration conflicts, the platform enforces a strict separation between parent landing pages and sub-page/family templates:

    • Parent Category Pages: The 8 root product categories (e.g. /products/geomembranes, /products/geotextiles) are governed inside the Site Builder visual hierarchy tree. Admin customizations in the Site Builder are merged onto premium fallback layouts.
    • Sub-Page Templates: Detailed family sub-pages (e.g. /products/geomembranes/hdpe-geomembranes) are governed inside Page Templates. Parent category slugs are strictly protected from creation here to prevent layout/navigation loop issues.

    4. XML Sitemap & SEO Discovery

    The dynamic sitemap at /sitemap.xml is auto-generated by a TanStack Start server route located in src/routes/sitemap[.]xml.ts. It automatically queries `template_product_categories` and includes all dynamic admin-created categories seamlessly, ensuring instant Google discovery without manual updates.
